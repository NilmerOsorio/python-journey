# 🌡️ Temperature Time Series Analysis with Pandas

## 📌 About the Project

This project was developed as part of the **Data Structures class at my university**, where we are learning to work with Pandas DataFrames.

The initial Python code was provided by our teacher as a starting point for a series of exercises. The goal was to practice data manipulation, analysis, and visualization while strengthening our Python programming skills.

## 🛠️ Technologies Used

- 🐍 **Python** — Main programming language.
- 🐼 **Pandas** — Working with Series, DataFrames, filtering, and moving averages.
- 🔢 **NumPy** — Generating simulated temperature data.
- 📊 **Matplotlib** — Visualizing temperatures over time.
- 🖥️ **Tkinter** — Displaying explanations through message boxes.
- 📁 **Excel** — Storing the generated dataset in `1000_days_temperature.xlsx`.

## 📂 Generated File

The program automatically generates **`1000_days_temperature.xlsx`**, an Excel file containing 1,000 dates and their corresponding simulated temperatures.

## 📚 What I Learned

Through these exercises, I practiced:

1. 🌡️ **Calculating averages** — Finding the average temperature over 1,000 days.
2. 🔎 **Counting conditions** — Identifying days with temperatures above 25°C.
3. 📈 **Finding maximum values** — Determining the highest temperature and its date.
4. 📊 **Data visualization** — Creating line graphs to analyze temperature patterns.
5. 📉 **Moving averages** — Using `.rolling(30).mean()` to smooth fluctuations and identify trends.
6. 🗓️ **Data filtering** — Selecting temperatures below 18°C within a specific date range.
7. ⚡ **Big data technologies** — Exploring InflexDB and its applications in large-scale time series processing.

## 💡 Key Takeaways

This project helped me understand how to manipulate Pandas DataFrames, apply conditional logic, work with dates, analyze time series, and visualize data.

It also showed me how Python libraries can work together to solve practical data analysis problems and why different technologies may be needed when datasets grow larger.

## 🎯 Conclusion

This is a **university learning project** based on exercises provided by our teacher. It represents one of my first steps toward understanding data analysis with Pandas and applying Python programming concepts to real-world-style problems.
