# 🐼 Pandas Practice

A collection of exercises to practice the basics of **Pandas** and data manipulation using Python.

## 📚 What I Practiced

* 📂 Loading CSV files with `pd.read_csv()`
* 📊 Working with DataFrames and Series
* 🔎 Selecting rows and columns
* 🎯 Filtering data with conditions
* ✅ Creating Boolean Series
* 🔗 Combining multiple conditions
* 🔢 Finding maximum values and averages
* 🔁 Iterating through DataFrame columns
* 🛠️ Creating functions to analyze data

## 🛠️ Technologies

* 🐍 Python
* 🐼 Pandas
* 📄 CSV

The exercises use a **video game characters dataset** to practice basic data analysis and manipulation.
