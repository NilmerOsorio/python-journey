# 🐼 Pandas Practice

A small collection of exercises focused on practicing **Pandas fundamentals** and basic data analysis with Python.

## 📚 What I Practiced

* Loading JSON data into a DataFrame
* Inspecting DataFrames (`shape`, `columns`, `tail`)
* Selecting columns
* Filtering data with conditions
* Boolean Series
* Combining multiple conditions with `&`
* Working with boolean and categorical data
* Calculating averages
* Using loops and functions with DataFrames
* Finding maximum values and corresponding records

The exercises gradually increase in difficulty, starting with basic DataFrame operations and ending with more logic-based problems.

## 🤖 My Approach to Learning

I use **AI as a practice tool, not as a code generator**.

Instead of asking AI for solutions, I ask it to **create exercises appropriate to what I'm currently learning**. I then solve them independently, test my code, and use AI for explanations or feedback when I get stuck.

> **AI gives me the problems. I write the solutions.**
