# 🐼 Pandas Data Selection

In this exercise, I learned the basics of **selecting and displaying data with Pandas** using an anime dataset.

## 📚 What I Learned

* Import Pandas with `import pandas as pd`.
* Load CSV files using `pd.read_csv()`.
* Set a column as the DataFrame index with `index_col`.
* Select columns using `[]`.
* Select multiple columns using a list of column names.
* Use `.to_string()` to display an entire column.
* Use `.loc[]` to select rows and columns by **labels**.
* Use `.iloc[]` to select rows and columns by **integer position**.
* Use slicing to select ranges of rows.
* Use the `step` value to skip rows when slicing.

## 🧠 Key Difference

| Method    | Uses              |
| --------- | ----------------- |
| `.loc[]`  | Labels            |
| `.iloc[]` | Integer positions |

This practice helped me understand how to navigate and retrieve specific data from a Pandas `DataFrame`.
