## 🐍📌 #1 — Python Basics

Welcome to the second entry of my learning journey! In this post, I dove into the core fundamentals of Python syntax, data types, and how Python interprets basic information under the hood.

### 🧠 What I Learned

* 🖨️ **Output & Inspection:** Mastered displaying text to the console using `print()` and using `type()` to inspect and verify data types dynamically.
* 💬 **Commenting Code:** Learned how to document code effectively using single-line comments (`#`) and multi-line comments or docstrings (`"""` / `'''`).
* 🔤 **Text Data (`str`):** Explored strings, learning how to use both single (`'`) and double (`"`) quotes interchangeably and handling basic text formatting.
* 🔢 **Numeric Types (`int`, `float`, `complex`):** 
  * Integers (`int`) for whole numbers.
  * Floating-point numbers (`float`) for decimals.
  * Complex numbers (`complex`) for mathematical calculations involving real and imaginary parts.
* ✅ **Logical Values (`bool`):** Understood Boolean values (`True` and `False`) which form the backbone of conditional logic and decision-making in code.

### 💡 Key Takeaways
Building a strong foundation with primitive data types is essential before moving on to complex data structures like lists, dictionaries, and custom functions. Every small concept practiced here brings me one step closer to writing cleaner, more efficient Python code.
