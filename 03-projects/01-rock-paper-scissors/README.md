# 🎮 Rock, Paper, Scissors — My First Python Project

This project marks the **beginning of my journey with Python**. I started by creating a simple **Rock, Paper, Scissors** game as a way to learn and practice the fundamental concepts of the language.

The main goal was to focus on the **basics of Python** before moving on to deeper and more complex topics. While building the game, I learned and practiced concepts such as:

* 🐍 Variables and data types
* 🖨️ `print()`
* ⌨️ `input()`
* 🔀 Conditional statements (`if`, `elif`, `else`)
* 🧩 Functions
* 📚 Dictionaries
* 🔁 Loops
* 🧠 Basic programming logic

Rather than simply following tutorials or studying each concept separately, I used the game as a small project where I could **apply these fundamentals in a practical way**.

## 🚀 Why I Built It

I wanted to make sure I had a good understanding of Python's core fundamentals before starting to explore more advanced topics.

The game gave me a simple environment where I could experiment with the language, make mistakes, solve problems, and understand how different basic concepts work together.

## 📖 What I Learned

This project helped me build a foundation in Python and become more comfortable with its syntax and basic programming logic.

It may be a small project, but it represents an important first step in my learning process. Now that I have practiced these fundamentals, I can start moving toward **deeper Python concepts and more complex projects**.
